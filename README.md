## About the game

A mobile card-swipe game combining Reigns mechanics with the early-2000s music industry. Manage a band from toilet venues to stadium stardom. Dark satirical tone.

For more information visit [daftdisco.com](https://daftdisco.com).

## Distribution policy

Binaries hosted here are intended for showcase reviewers, press, and authorised testers. Please do not redistribute the APK publicly without permission.
